# IndustryPulse 架构文档

## 三层架构

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   数据采集层     │────▶│   状态计算引擎   │────▶│   仪表盘/报告   │
│  (市场+财务+宏观) │     │  (指标→状态→信号) │     │  (可视化+诊断)   │
└─────────────────┘     └─────────────────┘     └─────────────────┘
        │                       │                       │
        ▼                       ▼                       ▼
   个股行情/财务数据         行业分化度(CSAD)         状态迁移图
   宏观信用指标(Phi)        信用环境指数            风险热力图
   市场波动率(VIX)          流动性状态              周期定位雷达图
                            综合健康度指数           投资建议面板
```

## 模块职责

| 模块 | 职责 | Phase |
|------|------|-------|
| `data_fetcher.py` | akshare → SQLite (行情/财务/宏观) | 1 |
| `db.py` | SQLite 建表/读写/upsert | 1 |
| `indicators.py` | CSAD / Phi / 健康度 / 四状态机 | 2 |
| `validator.py` | 样本外/置换/事件/回测 四方法验证 | 3 |
| `visualizer.py` | 雷达/时间轴/热力图/持续性 4 图 | 4 |
| `report_generator.py` | CSV + MD 报告一键生成 | 5 |
| `industry_pulse.py` | CLI 入口, 串联全流程 | - |

## GENESIS → IndustryPulse 映射

| GENESIS 原模块 | IndustryPulse 改造 | PE/VC 决策价值 |
|----------------|---------------------|----------------|
| CSAD (横截面离散度) | 行业分化度指数 | 分化越大越可能处于周期拐点 |
| Phi (BAA_Spread) | 信用环境指数 | 利差扩大=融资收紧, 募资退出变难 |
| VIX 通道 | 市场情绪/流动性 | 高波动下 IPO 窗口关闭 |
| 状态路由 (NORMAL/DEFENSE) | 行业周期四状态机 | 扩张→积极; 过热→谨慎; 收缩→观望; 筑底→布局 |
| 半马尔可夫持续时间 | 状态持续性分析 | "收缩期平均持续多久"——煎熬期判断 |
| 多方法证据评级 | 信号置信度框架 | 多维共振才触发状态切换 |

## 数据流

1. `DataFetcher` 抓固定股票池行情/财务 + 宏观利差, 写 `industry_pulse.db`
2. `IndustryStateMachine` 读库 → CSAD/Phi/动量 → 健康度 → 四状态, 写回 `industry_state` 表
3. `Validator` 对状态序列做四方法验证
4. `Visualizer` 生成单一 HTML 仪表盘
5. `ReportGenerator` 输出 CSV + 验证报告 + 投资摘要

## 关键设计取舍

- **固定股票池**: 成分股变动会导致 CSAD 不可比, 用某时点快照锁定池子
- **CSAD 去趋势**: `CSAD / 历史均值` 消除绝对水平漂移
- **混频对齐**: 日度市场指标平滑, 季度财务前向填充, 状态以月度为单位
- **分位数阈值**: 基于 2020-2024 历史动态计算, 不主观拍脑袋
- **状态防抖**: 最小保持期平滑, 体现半马尔可夫记忆性
