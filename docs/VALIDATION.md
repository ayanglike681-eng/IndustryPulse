# 验证方法论

## 核心问题

> 你怎么证明这个"状态机"不是事后诸葛亮?

直接从 GENESIS V9.0 方法论迁移, 用四方法交叉验证状态机可信度.

## 验证框架

| 方法 | 操作 | 通过标准 |
|------|------|----------|
| 样本外验证 | 2020-2024 训练阈值, 看 2025-2026 表现 | 状态判断与行业实际走势一致 |
| 置换检验 | 随机打乱个股收益率重算 CSAD | 真实 CSAD 显著异于随机 |
| 事件验证 | 检查已知行业事件 ↔ 状态切换 | 切换领先或同步于事件 |
| 策略回测 | 扩张期买入行业 ETF, 收缩期空仓 | 策略夏普 > 买入持有 |

## 已知行业事件锚点 (新能源/光伏)

| 时点 | 事件 | 期望状态 |
|------|------|----------|
| 2021-Q2 | 组件价格见顶回落, 健康度 +3→+1 | 预警过热 |
| 2023 | 光伏产能过剩显现 | CONTRACTION |
| 2024-Q4 | 行业触底出清 | BOTTOMING |

验证目标: 状态切换领先或同步于上述事件, 不滞后.

## 置换检验逻辑

1. 对每日个股收益率横截面做随机置换
2. 重算置换 CSAD 序列
3. 比较 真实 CSAD 均值 vs 置换分布
4. p < 0.05 → 真实分化度非随机, 状态信号有效

## 样本不对称的诚实声明

新能源行业 2020-2021 暴涨、2022-2024 暴跌, 样本天然不对称.
这恰是价值所在——状态机应能捕捉完整周期. 验证报告中专门分析:
- "2021-Q2 健康度 +3→+1, 提前 1 季度预警过热"
- "2022-Q4 进入筑底期, 2023-Q1 行业确实触底"

样本外数据有限时不夸大, 诚实标注局限.
